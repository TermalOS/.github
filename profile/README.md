**Termal OS** is a desktop app (Windows, macOS, Linux) that turns your Linux fleet into a real
desktop over SSH. Shared hosting, a VPS or a dedicated server - no agent to install, no root
required, no cloud in the middle. Your credentials are encrypted locally and never leave your machine.

### What it does

- 🖥️ **Remote desktop over SSH** - window manager, SFTP file explorer, a Monaco code editor, a
  multi-tab browser and a real PTY shell, all over one reusable connection.
- 📊 **Live monitoring** - CPU, RAM, disk, network, processes and history, pushed in real time.
- 🔔 **Smart alerts** - per-server thresholds and escalation to Telegram, Slack, Discord, webhook or email.
- 🐳 **Docker &amp; sites** - containers, hosted sites, PHP versions, git pull, visit stats.
- 🤖 **AI ops copilot** - diagnose and fix with reviewable commands, on **your own** API key.
- 🧩 **Termal Studio** - build your own mini-apps; see [`termalos-sdk`](https://github.com/TermalOS/termalos-sdk).
